# 0006. Video Matting Pipeline, Guided Matte Refinement, and Foreground Decontamination

## Context
Automatic video background removal in Sibcut Video Editor must deliver pixel-perfect cutout edges (no white/light halos, no color bleed around hair and motion-blurred boundaries, and temporal stability across frames) while maintaining smooth real-time playback on mid-tier laptops (integrated GPUs, 8–16 GB RAM) and complying with open-source distribution licenses (`GPL-3.0-only` application license and the 200 MB ASAR budget ceiling).

An audit of the initial RVM integration identified four architectural bottlenecks:
1. **WASM Module Resolution Failure in Bundled Builds**: Setting `ort.env.wasm.wasmPaths = './'` caused `new URL(filename, './')` inside `onnxruntime-web` to fail, falling back to a dynamic `import('./ort-wasm-simd-threaded.jsep.mjs')` relative to the bundled `/assets/index-<hash>.js` chunk (`404 Not Found` when served from root).
2. **Discarded Foreground Prediction (`fgr`), 2D Canvas Premultiplication Corruption, and Un-decontaminated Compositing**: `rvm_mobilenetv3.onnx` predicts both decontaminated foreground RGB (`fgr`) and continuous alpha (`pha`), but `segmenter.js` discarded `fgr`. Furthermore, staging the matte through an HTML 2D canvas (`putImageData`) premultiplied RGB by alpha, and `LAYER_FS` multiplied the composite source pixel $C = \alpha F + (1 - \alpha) B_{\text{old}}$ directly by $\alpha$, leaving $\alpha(1 - \alpha) B_{\text{old}}$ background halos around semi-transparent hair and soft edges.
3. **Unrefined Low-Resolution Bilinear Upsampling**: Sampling the `640×360` matte with raw bilinear filtering at 1080p/4K spread the alpha ramp across 2–3 background pixels outside the true subject boundary.
4. **Main-Thread Inference & Uncoalesced Queueing**: Running ONNX WASM inference on the main UI thread (~45–55 ms/frame) without single-flight frame coalescing stalled playback and allowed overlapping async runs to overwrite `Recurrent Matte State` out of temporal order.

## Decision
1. **Retain RobustVideoMatting (`rvm_mobilenetv3.onnx`, GPL-3.0) at `512×288` with Unpremultiplied Dual (`fgr` + `pha`) Upload**: Keep `rvm_mobilenetv3.onnx` (14.9 MB) as the core temporal matting network at `maxDim = 512` (`512×288` exact 16:9, where both dimensions are exact multiples of 32 for RVM's 4-stage stride-2 encoder) and pack its predicted foreground RGB (`fgr`) and continuous alpha (`pha`) into an unpremultiplied `Uint8Array` uploaded directly to the `MATTE_UNIT` `RGBA8` WebGL2 texture (`rgb = fgr`, `a = pha`), bypassing HTML 2D canvas premultiplication. Remove the unused legacy `person-segmenter.tflite` binary.
2. **Full-Resolution Guided Matte Refinement & Foreground Decontamination in `LAYER_FS`**: In the WebGL2 layer shader, refine the `512×288` alpha against the full-resolution source image (`u_tex`) via joint-bilateral guided edge weights (`matteRefined`) and unmix background color contamination at semi-transparent edge pixels (`foregroundDecontaminate`) using RVM's unpremultiplied `fgr` prior and local neighborhood foreground/background estimation. Expose **Foreground decontamination** (`decontaminate`: `0..100`, default `90` via `CUTOUT_DEFAULT_DECONTAMINATE`) and tuned `CUTOUT_DEFAULT` (`{ feather: 14, shrink: 2, smooth: 45 }`). Only apply `u_fgDecontaminate` when `u_cutOn == 1` so selective color grading (`colorTarget`) is unaffected.
3. **Deterministic Local WASM Resolution & Off-Main-Thread Single-Flight Execution**: Resolve ONNX Runtime Web module and binary URLs via `new URL('./', location.href).href`, execute inference in a dedicated Web Worker (`src/media/segmenter-worker.js`) sharing logic via `src/media/segmenter-core.js`, enforce single-flight coalescing per clip in `MatteCache`, and maintain a 48-frame LRU cache (`frameHistory`) that cleanly resets `recurrentState` upon non-contiguous cache hits or seeks.

## Considered Options
- **BiRefNet (MIT)**: Produces sharp single-frame masks at 1024×1024, but weights are 100–800+ MB (violating the 200 MB ASAR budget), lacks recurrent temporal state (causing frame-to-frame hair flicker on video), and requires hundreds of milliseconds per frame on laptop CPUs/iGPUs.
- **MatAnyone / VideoMaMa**: High-quality propagation matting, but licensed under non-commercial research licenses (`NTU S-Lab License 1.0` / `CC BY-NC 4.0`), making them incompatible with a distributed open-source (`GPL-3.0-only`) video editor.
- **MODNet / MediaPipe Selfie Segmenter (`Apache-2.0`)**: Lightweight, but lack temporal recurrent states and foreground color prediction (`fgr`), producing temporal edge chatter and coarse boundaries around loose hair.
