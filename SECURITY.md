# Security Policy

The Sibcut Video Editor project takes the security and privacy of its users seriously. As an offline-first desktop application handling user media, projects, and personal creations, maintaining a secure and safe software environment is our top priority.

---

## Supported Versions

Only the latest stable release of Sibcut Video Editor receives active security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or social media.**

If you discover a potential vulnerability, bug, or security risk in Sibcut Video Editor, please report it privately:

1. **Email the Creator & Maintainer**:
   Send an encrypted or detailed email to **Sina Sinaei** at [sina9100t@gmail.com](mailto:sina9100t@gmail.com).

2. **Include in your report**:
   - A clear description of the vulnerability.
   - Steps to reproduce or a minimal proof-of-concept.
   - The affected version(s) and operating system (Windows, macOS, Linux).
   - Any potential impact on user data or system integrity.

### Response Timeline
- **Acknowledgement**: You will receive an initial response within 48 hours acknowledging receipt of your report.
- **Investigation & Fix**: We will work to investigate and reproduce the issue, develop a patch, and coordinate an advisory or hotfix release.
- **Credit**: If requested, we will publicly credit you in the release notes and changelog once the vulnerability is resolved and patched.

Thank you for helping keep Sibcut Video Editor and its community safe!
